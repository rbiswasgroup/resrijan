# Code of conduct

ReSrijan follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good intent, and keep discussion about the work. Harassment of any kind is not tolerated.

Report unacceptable behaviour to the maintainer (contact details on the GitHub profile). Reports are handled confidentially.
